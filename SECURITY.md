# Security

AlongKit is designed to keep sensitive decisions explicit.

## Rules

- Do not store API keys in source files.
- Do not log secrets, bearer tokens, raw provider responses, or private user text.
- Use platform credential storage in app targets.
- Require explicit approval before sending messages, sharing location, contacting other people, or writing durable memory.
- Keep local mission history exportable and removable by the user.

## Security Reports

Please open a private report with a minimal reproduction and impact summary. Do not include live credentials or private user data in reports.
